## Methodology Notes

1. **λ derivation** — total goals expectation diturunkan dari devigged Over/Under 2.5 odds via bisection solver pada Poisson CDF.
2. **Home/away split** — total λ dibagi via grid search yang mereproduksi devigged 1X2 probabilities.
3. **Dixon-Coles correction** — ρ = -0.10 untuk koreksi low-score cells (0-0, 1-0, 0-1, 1-1).
4. **Devig** — margin bookmaker dihilangkan per pasar sebelum hitung gap (model_p − implied_devig).
5. **Per-market gate** — setiap market punya threshold model_min + gap_min sendiri (lihat `config.yaml`).
6. **Kelly/4** — quarter Kelly capped 5% bankroll (defensive sizing).

## Caveats

- Model **TIDAK pakai data eksternal** (tim form, injury, motivasi) — pure odds-internal arbitrage.
- Implementation matches SPEC.md sections 3-6 (parsing, model, edge calc).
- SPEC sections 4 (External Data API) dan 5 (Elo + form adjustment) **belum diimplementasi** — perlu API key untuk data provider.
- Edge yang diidentifikasi adalah **inkonsistensi internal pasar 1xbet** (e.g., AH +0.25 lines yang tidak match dengan 1X2 prices). Ini bisa jadi:
  - Real edge (bookmaker mistake)
  - Atau artifact model (Poisson tidak tangkap reality)
- Untuk validation true ROI, perlu backtest historikal seperti yang dilakukan di sesi sebelumnya.
